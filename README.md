# One Step Beyond - MVP

**One Step Beyond** es un videojuego de sigilo y exploración desarrollado en Unity 3D como parte del componente práctico del curso de Programación para Videojuegos de la UNAD. El proyecto busca integrar mecánicas de infiltración con la valorización y el conocimiento de la flora y fauna de los ecosistemas colombianos.

## 🎮 Descripción del Juego
El jugador debe explorar diferentes escenarios naturales manteniendo el sigilo para evitar ser detectado por los enemigos o el jefe de la zona. El propósito principal es recolectar especímenes endémicos clave, registrar información en la libreta de campo y activar la puerta de salida para avanzar en la aventura.

## ⚙️ Mecánicas Principales
* **Sigilo y Cobertura:** Uso de arbustos y zonas de camuflaje transparente para reducir la visibilidad frente a la IA enemiga.
* **Recolección e Inventario:** Interacción por proximidad (tecla **F**) para recolectar elementos y visualizarlos en el panel de misión.
* **Progresión y Salida:** Al recolectar los 3 objetos requeridos en el mapa, se habilita la puerta de salida hacia el siguiente nivel.
* **Accesibilidad:** Interfaz adaptada con elementos visuales claros y retroalimentación de alertas.

## 🕹️ Controles Básicos
* **Movimiento:** Teclas `W`, `A`, `S`, `D` / Flechas direccionales.
* **Interactuar / Recolectar:** Tecla `F`.
* **Ocultarse:** Posicionarse dentro de las zonas de arbustos designadas.

## 🛠️ Aspectos Técnicos
* **Motor de desarrollo:** Unity 3D (Unity 6)
* **Lenguaje de programación:** C# (con comentarios técnicos en inglés)
* **Control de versiones:** Git y GitHub (Rama de integración oficial: `feature/stage-3-integration`)
